## Define：问题与完成标准

译者需要在选择字幕、修改正文和下载文件时看到当前操作相关的规则与下一步，因为原有集中说明及通用反馈不足以解释字幕约束和禁用状态。

完成标准：SRT / WebVTT / TXT 混合任务提示正确；非法字幕位置可见；非法保存保留草稿；合法多行保存与下载可用；下载失败可重试；新提示键盘可达、亮暗可读；不增加前端正文校验或改变后端格式保护规则。

## Develop：方案取舍与实现

比较了两种做法：把所有字幕说明集中在导入页，或者按导入、编辑、导出分别给出就近说明。采用后者，避免用户在编辑时回忆导入页内容，也避免普通 TXT 分段承担无关的字幕说明。

- 导入：分开呈现文档/字幕类型、数量/总大小限制、各文件预期格式与容量；字幕选择显示固定分段、编码及 WebVTT 轨道说明。字幕不出现 TXT 分段设置，混合任务只对 TXT 展示该设置。校验失败时禁用创建，修正选择后恢复。
- 编辑：共享组件接收后端任务/成员格式，按 `sourceFileName` 匹配成员；不靠文件后缀猜测已导入内容。提示合法换行与草稿保留，使用 MudTextField.HelperId 关联说明。移除译文占位符的 aria-hidden 冲突；没有标记的分段不显示无关的占位符说明。
- 导出：按钮区分 SRT、WebVTT、ZIP；解释未保存、运行中和未完成状态；显示准备下载状态。失败保留可重试横幅；旧任务的下载响应不在新任务页面继续触发下载或提示。
- 导航：任务头直接进入编辑区；锚点包含当前任务路径，验证不会受 Blazor base URL 影响跳到首页。
- 可读性：字幕导入提示使用正文主题色，图标及提示背景保留 info 语义，避免蓝色小字对比度不足。

实现仍使用 MudBlazor、RCL、资源文件及现有 CSS token；无新依赖、无新增 JS 桥、无 API 字段变更。
