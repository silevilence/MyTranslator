# 设计规范

## 1. 设计原则

1. **桌面优先**：双端皆为桌面形态，不做手机适配；最小支持宽度 1024px（低于时横向滚动，不重排）。
2. **双端通用**：一份设计、一套组件服务 Web 与 MAUI 两端；差异仅在窗口/导航层处理。
3. **状态语义化**：任何状态不得只靠颜色传达，必须"颜色 + 图标 + 文字"三通道（红绿色盲可读）。
4. **信息密度优先**：CAT 工具长时高密度工作，紧凑密度为默认。
5. **默认不丢数据**：编辑切换即存、危险操作确认、离开未保存内容前提示。
6. **用库不造轮子**：经确认安全的成熟 NuGet 库直接使用，只自研领域组件（ADR-0001）。

## 2. 视觉 Token

所有视觉值通过 MudBlazor `MudTheme` 定义。页面代码禁止散落硬编码色值/字号（审查必检）。

### 2.1 主色

| Token | 值（亮色） | 用途 |
|---|---|---|
| Primary | `#2563EB` 系（覆盖 MudTheme palette） | 主操作、选中态、链接、品牌 |
| Secondary | MudBlazor 默认 blue-grey | 次级操作 |
| Background / Surface | MudBlazor 默认 | 页面 / 卡片底色 |

**暗色模式**：`MudThemeProvider` 提供亮/暗两套 palette，语义 token 在暗色下与亮色一一对应（同一语义、不同色值，由主题定义）。跟随系统设置，应用内可手动切换（选择持久化到 localStorage）。审查时双主题过检。

### 2.2 语义色映射（与翻译域状态一一对应，禁止跨用）

| 语义 token | 翻译域含义 | 示例场景 |
|---|---|---|
| success（绿） | 分段已确认 | 确认状态徽标、保存成功 |
| warning（琥珀） | TM 差异过大告警 | 差异告警标记 |
| error（红） | 规则违规（占位符破坏/漏翻） | 违规徽标、危险操作确认按钮 |
| info（蓝） | AI 审核意见 / 提示 | 审核意见条、参考信息 |
| neutral（灰） | 未翻译 / 待确认 / 禁用 | 默认分段状态 |

规则：
- 状态色只能按上表语义使用；禁止反向（如红色表示"告警"、琥珀表示"违规"）。
- 状态呈现一律三通道（颜色 + 图标 + 文字）。

## 3. 字体

不捆绑字体文件（CJK 字体体积过大，WASM 首屏与镜像体积受损），全部走系统字体栈，经主题注入。

### 3.1 UI 字体栈（必须按此顺序）

```
"Segoe UI", "Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", "Source Han Sans SC", sans-serif
```

### 3.2 等宽字体栈（占位符 / 标记 / 分段 ID / 差异文本 / 代码内容）

```
"Cascadia Code", "JetBrains Mono", Consolas, "Courier New", monospace
```

占位符类内容强制等宽：`{0}`、`<tag>` 中 `O0`、`l1` 之类肉眼可分。

### 3.3 字号层级

| 层级 | 字号 | 用途 |
|---|---|---|
| H1 | 20px / 600 | 页面标题 |
| H2 | 16px / 600 | 区块标题 |
| 正文 | 14px | 默认文本 |
| 辅助 | 12px | 元信息、徽标、表格次要列 |
| Mono | 13px | 等宽内容 |

正文对比度 ≥ 4.5:1（亮/暗两主题均须验证，见审查标准维度四）。

## 4. 布局与自适应

### 4.1 断点（桌面三档）

| 断点 | 布局行为 |
|---|---|
| ≥ 1600px | 宽屏：编辑器双栏并排 + 可选看板侧栏 |
| 1280 – 1600px | 标准：编辑器双栏 |
| 1024 – 1280px | 紧凑：详情面板改为抽屉 / 下叠 |
| < 1024px | 不支持：内容区横向滚动，不做重排 |

自适应手段：CSS 变量 + MudBlazor `BreakpointProvider`（组件级隐藏/重排）；禁止散落媒体查询。

### 4.2 间距

4px 网格。组件间距使用 MudBlazor 间距工具类（4 的倍数）；紧凑密度为默认。

### 4.3 面板模式

编辑器"分段列表 ⇄ 详情面板"使用可折叠/可拖拽分割面板；分割比例与折叠状态持久化到 localStorage。

### 4.4 MAUI 差异

- 窗口最小尺寸 1024×700；
- 无浏览器地址栏：应用内"关于/设置"入口承担版本与后端地址信息；
- 快捷键与 Web 端一致（键盘事件由 Blazor Hybrid 转发，见《交互规范》§5）。
