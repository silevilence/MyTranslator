# 组件规范

## 1. 组件分层

```
通用组件（MudBlazor）── 领域组件（RCL 自研）── 页面
```

- 通用能力（按钮/表格/弹窗/表单/菜单/进度等）一律使用 MudBlazor，**禁止自研**（ADR-0001）。
- 领域组件（MudBlazor 未覆盖的 CAT 特有组件）在 RCL 自研。
- 页面只组装，不内联实现领域逻辑。

## 2. MudBlazor 使用约定

- 版本锁定，不随手升级；升级走独立提交并双端（WASM + MAUI）验证。
- 主题：唯一 `MudThemeProvider` + `MudTheme`（根组件注入），含亮/暗两套 palette 与语义色映射（《设计规范》§2）。
- 禁止直接覆写 Mud 组件内部 CSS 类；定制通过主题 / `Class` / `Style` 参数完成。
- 需要扩展的 Mud 组件：封装为 RCL 组件并补文档，禁止在页面内复制 Mud 用法碎片。
- 长列表（分段、术语）必须虚拟化：`MudTable` 虚拟化或 `MudVirtualizedList`。

## 3. 自研领域组件清单（RCL，名称即契约）

| 组件 | 行为契约（必须） |
|---|---|
| `SegmentList` 分段列表 | 只读展示原文/译文/状态/违规标记；行选中；键盘导航（↑/↓）；脏标记展示 |
| `SegmentEditorPanel` 详情面板 | 译文编辑、原文对照、TM 参考、术语提示、审核意见、保存/确认操作 |
| `DiffViewer` 差异对比 | TM 相似译文与当前译文的并排/逐字差异高亮 |
| `ProgressBoard` 进度看板 | 任务状态 + 完成度（分段完成数/总数）百分比 |
| `RuleViolationBadge` 违规徽标 | 规则违规：红 + 图标 + 违规类型文字（三通道） |
| `TermHint` 术语提示 | 术语对齐提示：期望术语 vs 实际用词 |
| `ReviewPanel` 审核意见面板 | AI 审核意见（问题描述/修改建议）按分段展示 |
| `ConfirmDialog` 危险操作确认 | 封装 MudDialog：后果说明 + 红字"确认"按钮 |
| `EmptyState` 空态 | 统一模板：图标 + 一句说明 + 主行动按钮 |
| `ErrorBanner` 错误横幅 | 页级错误 + 重试按钮 |
| `KeyboardHelp` 快捷键帮助 | `?` 触发，展示快捷键表（《交互规范》§5） |
| `DirtyMark` 脏标记 | 未保存状态 `●` 展示 |

## 4. 组件开发约定

- 命名：`PascalCase`，语义化，不缩写。
- 参数：公开参数必须有 XML 注释；回调显式命名（`OnSave` / `OnConfirm` 等）。
- 样式：组件级 CSS 隔离（`.razor.css`）；禁止行内 `style`（动态值除外）。跨组件共享的**纯布局类**（不含语义色/主题色值）可入 RCL 全局样式表 `mt.css`（类名 `mt-` 前缀）；组件专属样式仍须 `.razor.css` 隔离。
- 文案：所有用户可见字符串进 resx（§5），组件内禁止硬编码中文。
- 状态：组件内部状态自洽；跨页状态走 DI 服务，不通过组件参数层层透传。

## 5. resx 约定

- 资源文件统一放 `Resources/` 目录，按页面/组件分文件（如 `SegmentEditor.resx`）。
- v1 仅中文：默认 resx 即中文，不做运行时语言切换。
- 审查检查：页面/组件代码中用户可见中文字符串字面量为零（测试代码除外）。
