# 交互规范

## 1. 页面骨架与导航

- 布局：左侧导航栏 + 内容区。导航项：任务、术语表、Token 管理（+ 设置）。
- 路由：`/` 任务列表；`/tasks/{id}` 任务详情（编辑器）；`/terms` 术语表；`/tokens` Token 管理；`/settings` 设置。
- 登录与 401：未持 Token → 强制登录页；Token 持久化 localStorage；全局 HTTP 客户端自动附加 `Authorization: Bearer`；任意请求 401 → 清理 Token 并跳登录。
- 设置页（`/settings`）：AI 提供商/模型两级配置管理（ADR-0003）。提供商 CRUD（kind/BaseUrl/密钥、启用、默认对设置；密钥只回显掩码、编辑留空即保持）+ 模型 CRUD（厂商模型 ID/展示名/能力标注）；保存即时生效并 Snackbar 提示；未配置默认对时提示将影响翻译。翻译操作面板的提供商/模型选择器缺省显示默认对，选择按任务维度持久化到 localStorage，刷新后恢复；提交翻译随请求携带 `providerId`/`modelId`（三档解析）。配置状态异常（未配置默认对、选择不可解析）时提示并给出「前往设置」入口；错误文案按 `docs/back` 错误码映射生成。

## 2. 编辑器交互模型（核心）

- 双栏：左 = `SegmentList`（只读），右 = `SegmentEditorPanel`（编辑）。
- 选中分段：点击行选中；`↑`/`↓` 切换（切换即触发保存）；`F2` 打开详情面板。
- 保存时机：**切换分段 / 确认操作时自动保存**；`Ctrl+S` 手动兜底；未保存显示脏标记 `●`；离开含未保存内容的页面时提示。
- 确认状态流转：`待翻译 → 已翻译（AI 翻译后自动）→ 已确认（人工）`；已确认可取消确认。
- 批量操作：列表表头工具条（多选 → 批量确认/取消确认），编辑器增强阶段实现。
- 快捷键帮助：`?` 打开 `KeyboardHelp` 浮层。

## 3. 反馈分级体系

| 场景 | 呈现 | 细则 |
|---|---|---|
| 操作结果（保存成功/失败） | Snackbar | 3–5 秒自动消失；失败含错误码映射文案 + 重试动作 |
| 页级错误（加载失败/接口不可用） | ErrorBanner | 页内横幅 + 重试按钮；不弹窗 |
| 长任务（AI 翻译/审核） | 进度条 + 百分比 + 阶段文案 | 与任务状态联动；失败可重试 |
| 列表/区块加载 | 骨架屏 | 不用转圈 |
| 按钮提交中 | 按钮 loading + 防重复提交 | 提交期间禁用 |
| 空态 | EmptyState | 图标 + 一句说明 + 主行动按钮 |
| 危险操作（删除术语/撤销 Token/清空译文） | ConfirmDialog | 后果说明 + 红字"确认" |
| 表单校验 | 字段级行内错误 | 提交时汇总提示 |

错误文案：由 `docs/back` 错误码 → 前端映射表生成，禁止页面散落硬编码错误文案。

## 4. 任务状态呈现

| 任务状态 | 徽标呈现 |
|---|---|
| 创建 | neutral 灰 |
| 处理中 | info 蓝 + 进度条 |
| 完成 | success 绿 |
| 失败 | error 红 + 重试入口 |

## 5. 快捷键表（两端一致）

| 快捷键 | 动作 |
|---|---|
| `↑` / `↓` | 切换分段（自动保存当前） |
| `Ctrl+Enter` | 确认当前分段并跳下一段 |
| `Ctrl+S` | 手动保存 |
| `F2` | 打开详情面板 |
| `?` | 快捷键帮助 |
| `Esc` | 关闭弹窗/抽屉 |
