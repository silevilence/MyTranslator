本次增加 54 个测试用例（API 44、Shared 10）。专用测试入口：

- `SpecializedTranslationConfigurationTests`：三格式 CRUD 回显、非法值、缺省兼容及迁移升级/回退；存量模型和运行默认 general。
- `SpecializedTranslationExecutionTests`：两格式 × 两连接器 × 有无术语；实际 HTTP 中单条 user、无 system/历史/工具/JSON 模式；完整语言名、Index 原生关闭思考；失败段有限重试、成功段不重复请求、运行快照、预算无请求、参数拒绝、空响应/截断/回显/占位符破坏。
- `SpecializedTranslationReviewTests`：显式模型、提供商默认和全局默认三种解析路径均拒绝专用审核；创建后改格式、首次响应后改格式均阻止后续审核请求；译文与任务状态不变。
- `SpecializedTranslationRegressionTests`：取消后中断恢复保留成功分段及格式快照、释放活动运行；语言对/大小写/术语整条预算；源文本模板标记保留；两格式 × 两连接器的混合多文件导出。
- Shared：三格式请求/响应序列化、旧响应缺省 general、七个新增错误码的统一中文映射。

完整测试继续覆盖通用批量 JSON 翻译、AI 审核、`task_busy`、txt/markdown/html/epub 及字幕导入导出。新增混合任务包含 txt、markdown、html、SRT、WebVTT，逐成员比较导出正文与受保护内容，确认多行仍归属同一字幕分段、条目及时间轴未改变。

## 真实浏览器

使用 Codex 内置 Chromium、1280×720 桌面窗口，前端发布目录配合同源 API 代理；独立数据库和本地固定响应模型，不读写用户生产配置，不向外部传输样例。

1. 在设置页创建 `hy-fixture`（HY-MT2）、`index-fixture`（Index）与 `general-fixture`（通用）；刷新仍显示正确格式。
2. 默认对为 HY-MT2，启动固定样例 `Hello world.` 的翻译，完成 1/1，查看译文 `你好，世界。`。
3. 尚无通用模型时，审核按钮禁用，直接提示配置通用模型并提供设置入口，专用翻译可正常完成。
4. 显式选择 Index；即使其「支持调整思考等级」已开启，思考等级仍禁用并显示关闭，翻译完成 1/1，运行回显关闭。
5. 加入通用模型后刷新任务，Index 选择和译文保留；审核提示明确选择通用模型。审核下拉中两种专用格式禁用，键盘选择通用模型后审核完成 1/1、0 条审核意见，译文保持不变。
6. 检查亮/暗两主题、格式标签、提示文案、Tab/Esc、弹窗焦点循环及归还；五维审查通过，见[前端审查记录](../front/专用翻译模型审查记录.md)。

本机截图与隔离服务文件保存在忽略目录 `.scratch/specialized-translation/`：`settings-light.png`、`settings-dark.png`、`review-completed.png`。这些是本次验证证据，不是发布依赖。
