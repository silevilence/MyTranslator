# 鉴权与基础接口约定

## 基础地址与公开接口

- 开发环境后端地址：`http://localhost:5199`
- 所有业务接口统一使用 `/api` 前缀，并默认要求 Token 鉴权。
- 公开白名单：`/swagger`、`/swagger/v1/swagger.json`。Swagger 仅公开接口结构，不公开任何 Token。
- 开发环境允许浏览器跨源请求；非开发环境只允许配置项 `Cors:AllowedOrigins` 中列出的来源。

## Token 来源

部署环境必须通过环境变量 `INITIAL_TOKEN` 提供初始 Token，格式为：

```text
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

其中 `x` 是 32 个十六进制字符。应用首次启动时自动执行 SQLite 迁移并写入初始 Token；数据库只保存 Token 的 SHA-256 摘要和可识别前缀，不保存明文。

开发环境未配置 `INITIAL_TOKEN` 时，自动启用以下固定 Token，并在启动日志中警告：

```text
sk-dev-00000000000000000000000000000000
```

开发 Token 与生产 Token 使用同一套存库校验流程。非开发环境缺少或配置了格式错误的 `INITIAL_TOKEN` 时，应用拒绝启动。

## 请求头

所有受保护接口必须携带：

```http
Authorization: Bearer sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

示例：

```bash
curl http://localhost:5199/api/health \
  -H "Authorization: Bearer sk-dev-00000000000000000000000000000000"
```

成功响应：

```json
{
  "status": "healthy"
}
```

## Token 管理 API

Token 管理接口本身也要求有效 Token。

### 生成 Token

`POST /api/tokens`

```json
{
  "name": "External integration"
}
```

返回 `201 Created`。完整 Token 只在本次响应中出现，调用方必须立即安全保存：

```json
{
  "id": "d63929ad-54ea-4f83-aa2c-a456f2825210",
  "name": "External integration",
  "token": "sk-0123456789abcdef0123456789abcdef"
}
```

### 列出 Token

`GET /api/tokens`

返回 `200 OK`，包含有效和已撤销 Token。列表只展示明文前缀：

```json
[
  {
    "id": "d63929ad-54ea-4f83-aa2c-a456f2825210",
    "name": "External integration",
    "tokenPrefix": "sk-0123456789ab",
    "createdAt": "2026-08-13T00:00:00+00:00",
    "revokedAt": null
  }
]
```

### 撤销 Token

`DELETE /api/tokens/{id}`

- Token 存在时返回 `204 No Content`；重复撤销同一 Token仍返回 `204`。
- Token 不存在时返回 `404 Not Found`。
- 撤销提交后立即生效，后续使用该 Token 的请求返回 `401 Unauthorized`。

## 错误响应

错误统一使用 `application/problem+json` 兼容的 Problem Details 字段：

```json
{
  "type": "https://httpstatuses.com/401",
  "title": "Unauthorized",
  "status": 401,
  "instance": "/api/health"
}
```

| HTTP 状态 | 含义 |
|---|---|
| `400 Bad Request` | 请求体缺失、格式错误或字段校验失败 |
| `401 Unauthorized` | 未携带 Token、请求头不是 Bearer 格式、Token 伪造或已撤销 |
| `403 Forbidden` | 已认证但无权执行操作（供后续权限策略使用） |
| `404 Not Found` | 路由或指定资源不存在 |
| `500 Internal Server Error` | 未处理的服务端错误；响应不暴露内部异常细节 |
