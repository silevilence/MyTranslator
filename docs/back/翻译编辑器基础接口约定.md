# 翻译编辑器基础接口约定

本页记录功能验证版前端与《任务管理接口约定》的对接，不新增私有接口。

## 数据与保存

- `/tasks/{id}` 使用共享 `TranslationEditor`、`SegmentList`、`SegmentEditorPanel`；列表只读，详情面板编辑。首次 GET segments，按 nextCursor 加载更多；已加载分段使用虚拟化表格，多选最多 200 项。
- 草稿绑定 taskId、extractionRevision、segmentId 和原 version；保存 PUT `/api/tasks/{taskId}/segments/{segmentId}`，请求只含 targetText、confirmationStatus 与并发/语言上下文。
- 标记表决定只读片段，普通文本间隙使用输入框，不能改写或删除标记；hover 和可见文字均提供标记含义。用户在普通文本中伪造引用时仍由后端 422 拒绝，保留草稿。
- 切换分段、确认、Ctrl+S 自动/手动保存共用同一路径。未保存显示 ●；保存失败不切换、不清草稿，显示映射文案、Snackbar 与重试入口。普通编辑使旧确认变为 translated，需再次明确确认。
- 确认与批量确认使用页面明确语言对；未填完整时后端 tm_language_pair_required，不猜测语言。语言对在 localStorage 按任务持久化，仍不保存 Token 以外的秘密数据。
- 批量确认先保存当前草稿，再 POST segment-confirmations，提交所选各分段最新 version；一个批次原子成功/失败，不提交整表假定成功。
- 清空译文、放弃草稿、内部导航均有确认；外部导航/刷新使用浏览器未保存提示。原译文空白归 null，clear 搭配 pending。

## 刷新与关联区域

- 保存成功返回完整分段，更新列表与详情，再 GET task 更新状态/导出能力。后续看板使用服务端 progress。
- AI 审核意见从原行内展开迁移到详情 `ReviewPanel`；普通编辑不清空旧意见。已有 TM 对比也进入详情，按分段版本/语言对重新请求。
- 后台翻译/审核提交后刷新已加载分段；本地脏草稿保留原版本，不能被轮询覆盖。版本冲突需保留草稿后显式刷新/重新编辑。
- 重提取修订改变后旧列表/草稿失效，脏草稿需先确认放弃。手头有未保存内容时，页面禁止触发翻译/审核、导出和重提取，先处理保存。
- 所有请求走共享 ApiClient，401 复用全局清 Token/登录；凭据已失效时放行登录跳转，不被草稿导航确认拦截。错误码文案映射以任务、规则与 TM 契约为准。快速切换任务时，旧任务摘要与语言加载响应不得覆盖新任务。

## 快捷键与后续正式界面

列表 ↑/↓ 保存并切换；Ctrl+Enter 确认并下一段；Ctrl+S 保存；F2 聚焦详情；列表/工具栏 ? 显示帮助；Esc 关闭弹窗。文本框中的方向键、问号保留编辑语义。JS 仅取消浏览器默认按键动作，操作与状态由 C# 实现。

用户已于 2026-09-12 确认：暂用固定双栏，拖拽分栏、分栏比例持久化及视觉精修验收留待正式前端。代码 TODO 位于 TranslationEditor、SegmentEditorPanel、SegmentList，后续替换布局/内联编辑外观时保留接口、草稿与占位符保护边界。

## 验证记录

共享层测试 172 项通过；草稿模型及保存客户端行覆盖率 100%。Web 构建零警告、零错误。
真实浏览器配独立 SQLite/API 验证：登录、切换即存、Ctrl+S、批量确认、刷新不丢数据、并发冲突保留草稿、放弃草稿确认及快捷键帮助通过。未以此宣称 Razor 组件行覆盖率或正式视觉验收完成。
