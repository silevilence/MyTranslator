# 任务参考资料与多术语表接口约定

2026-10-28 增量，扩展术语、任务、AI 翻译与审核接口；与旧文档重叠时以本文为准。

## 术语表

- 新资源 `GET /api/glossaries?limit=100&cursor=…`（1..200，按 id 升序，不透明游标），返回 `{items:[{id,name,version}],nextCursor}`；`POST /api/glossaries` 接受 `{name}`，去首尾空白后 1..100 字符，返回 201。`PUT /api/glossaries/{id}` 接受 `{name,version}`，返回递增版本；`DELETE /api/glossaries/{id}?version=…` 返回 204，仅允许删除空且未绑定任务的非默认表。
- 迁移将已有词条及任务关联至“默认术语表”（`00000000-0000-0000-0000-000000000001`），新任务也默认选中该表，可手动选择其他表或不使用术语表。
- `GET /api/terms` 新增 `glossaryId`，缺省选择默认表，游标绑定此条件。创建术语可传 `glossaryId`（缺省或 null 为默认表）；响应回显该字段。更新不迁移词条所属表。唯一性改为“表 + 语言对 + 规范化源术语”，不同表允许不同译法。
- 术语表不存在：404 `glossary_not_found`；ID 格式错误：400 `invalid_glossary_id`；名称无效：400 `invalid_glossary_name`；版本无效：400 `invalid_glossary_version`；版本冲突：409 `glossary_version_conflict`；删除默认表、非空表或被任务引用的表：409 `glossary_in_use`。

## 任务参考资料

`GET /api/tasks/{id}/reference` 返回 `{glossaryId,backgroundInformation,version}`。`PUT` 同一路径完整替换，必须携带这三个字段；`glossaryId=null` 不使用术语表；背景 null/纯空白规范化为 null，非空去首尾空白后最多 4000 个 UTF-16 单元。版本从 1 开始，成功保存递增。

更新纳入 TaskOperationLock 与事务，活动翻译/审核返回 409 `task_busy`；版本不匹配返回 409 `task_reference_version_conflict`；版本非法返回 400 `invalid_task_reference_version`；背景类型或长度无效返回 400 `invalid_background_information`。任务不存在返回 404 `task_not_found`。修改不改变提取修订、译文或已有审核意见，下次运行使用新资料。

翻译（包括通用模型）和审核创建时固定所选表中对应语言对的词条与背景快照，全部批次和重试沿用。只注入当前分段命中的词条，源语言自动识别时不注入术语；未选表则不注入术语。术语对齐检查仅检查当前绑定表。背景不受源语言自动识别限制。

- 普通对话模型的翻译与审核将非空背景放入 System 作为参考资料，并保留输出格式、占位符等要求。
- Index 将背景作为约束区参考信息；HY-MT2 使用 `【背景信息】` 区块与 `【待翻译文本】` 分隔。专用模型仍只有一条 user 消息。背景计入完整请求预算，不截断。
- 空背景不生成区块。背景不进入日志或运行公开资源。审核仍只允许 general 模型。

## 审核思考等级

创建审核新增可选 `reasoningEffort`：null、none、low、medium、high、xhigh；非法类型/值返回 400 `invalid_reasoning_effort`。显式等级要求模型 supportsThinking=true，Ollama 不接受 xhigh，否则 422 `reasoning_not_supported`。等级存入运行，在创建、详情和列表回显；每次请求和重试使用同一等级。默认不发送，开启思考时不强制 temperature=0。

## 前端

左侧“术语表”页提供表选择、新建、重命名及删除，选中表后管理词条。任务详情在运行操作前显示“参考资料”：选择一份术语表或不使用、可选背景、显式保存；有未保存内容时阻止开始运行，并提示保存或取消。切换任务不得带入旧资料，保存后刷新术语检查。运行中禁用修改。术语实际生效要求翻译/审核明确填写源语言，与表内词条语言对匹配。

审核提供与翻译一致的思考等级选择与运行实际等级回显。所有文案进 resx，错误按 code 映射，术语表切换丢弃旧游标和晚到响应。
