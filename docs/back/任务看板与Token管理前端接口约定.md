# 任务看板与 Token 管理前端接口约定

本页对接《任务管理接口约定》《文件导入拆解与导出接口约定》《鉴权与基础接口约定》，不增加私有后端接口。

## 任务列表和看板

`/` 页面组装共享 `TaskDashboard`。GET `/api/tasks?limit=100&status=...&cursor=...` 加载任务，复用上传/URL 创建入口及状态筛选。
`ProgressBoard` 在列表与任务详情显示状态、已有译文数/总分段数及百分比、已确认数/总分段数及百分比。受保护块不计入；零分段为 100%。完成与确认是两个独立指标。
列表每 3 秒刷新当前筛选下已加载页，保留画面内容，不每次清屏。发生外部翻译、人工保存、确认或新建任务后，下一次刷新更新；状态筛选改变会废弃旧游标与在途旧代次响应。分页按 taskId 去重。
轮询失败保留已有数据并提供错误横幅/重试，页面离开取消计时与请求。详情在本页保存成功和翻译/审核状态更新后重新 GET task，同步进度和导出能力。

## Token 页

`/tokens` 为受保护路由，导航已启用，页面只组装共享 `TokenManagementPanel`。

| 操作 | 请求 | 行为 |
|---|---|---|
| 列表 | GET /api/tokens | 展示 name、tokenPrefix、createdAt、revokedAt 状态，不含完整凭据。|
| 生成 | POST /api/tokens，JSON name | 名称去首尾空白，1..100 字符；完整 token 只保留在当前组件内存中一次性展示，可复制或隐藏；隐藏/离页后不能重取。|
| 撤销 | DELETE /api/tokens/{id} | ConfirmDialog 说明立即失效及撤销自身会退出，确认后提交；成功刷新列表，已撤销条目禁止重复操作。|

生成成功但列表刷新失败时仍保留新凭据，防止丢失一次性响应。完整凭据显示期间禁止再次生成覆盖它；隐藏后可继续创建。不把生成的 Token 自动设为登录凭据，也不写 localStorage、日志或 URL。
撤销当前登录 Token 后，刷新列表的请求返回 401，全局 ApiClient 清除登录 Token 并跳登录。生成/撤销期间按钮禁用，防止重复提交。400/401/404 与网络异常使用统一错误映射，不臆造 Token 专属错误码。
列表骨架、空态、页级错误、字段校验和动态更新播报均保留；现有主题直接复用。

TaskDashboard、ProgressBoard、TokenManagementPanel 均有功能验证版 TODO，后续正式前端替换呈现时保留接口、轮询代次、取消及一次性凭据边界。

验证：共享层 183 项测试通过；Web 构建零警告零错误。真实浏览器验证外部确认后看板自动更新、新 Token 鉴权成功、撤销后立即 401、撤销自身清凭据并退出，以及共享组件资源名称正确解析。
