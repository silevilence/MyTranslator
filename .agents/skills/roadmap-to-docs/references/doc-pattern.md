# docs/back 约定文档家族模式

从既有文档（《鉴权与基础接口约定》《文件导入拆解与导出接口约定》）归纳的家族格式。写任何新文档前先读本文与上述两份既有文档，保持格式、措辞与交叉引用一致。

## 1. 文档骨架

1. 标题：`# <功能名>接口约定`
2. 导言段：说明本文范围与覆盖的调用方（Web 端、桌面端、第三方系统）；首段或首节即引用基础文档：「鉴权、基础地址和通用 Problem Details 格式以《鉴权与基础接口约定》为准。本文所有接口均要求 Bearer Token。」
3. 分节顺序：`范围与接口原则` → `通用约定` → 各接口定义（按资源分节） → 错误码 → 与既有文档的关系/预留。
4. 末尾固化语句：明确本文承诺不改变或预留的既有语义（例如「不得改变分段字段语义」「本文预留任务状态字段，由后续文档补充」）。

## 2. 通用约定（每个新文档都写，措辞可复用）

- **标识/时间/枚举**：`taskId`、`segmentId` 等为 UUID 字符串；时间用 UTC ISO 8601（`2026-08-13T08:30:00Z`）；枚举用英文小写字符串；调用方必须容忍未来新增未知枚举值；JSON 字段 `camelCase`；UTF-8。
- **分页**：游标分页 `?limit={}&cursor={opaqueCursor}`；`limit` 默认 100、范围给出（如 1..200）；`cursor` 不透明、不可解析构造；`nextCursor: null` 表示末页；游标绑定产生它的提取修订，失效返回 `409` 且错误码说明原因（如 `extraction_revision_changed`）。
- **任务公共状态**：`created` / `processing` / `completed` / `failed`；响应中引用该状态集时用表格列出值含义。
- **鉴权**：一律引用基础文档，不重复 Token 格式与 401 语义。

## 3. 接口定义格式

- 小节标题：`### <HTTP 动词> <路径>`。
- 每个接口依次给出：请求说明（表格或列表）→ 请求体 JSON 示例（```json 代码块）→ curl 示例（含 `-H "Authorization: Bearer …"`）→ 成功响应示例（标注 HTTP 状态）→ 约束/边界行为列表。
- 响应字段用「字段 | 约束」或「字段 | 类型 | 必填 | 说明」表格固化。
- 失败一律给出：HTTP 状态 + 机器可读错误码（如 `400 unable_to_infer_file_type`、`422 import_parse_failed`）+ 含义；错误响应体为 Problem Details，只补充 `title`/`instance` 等字段，不重复定义格式。

## 4. 既有契约要点（写新文档必须保持一致）

- **分段契约**（《文件导入拆解与导出接口约定》定义，后续文档只引用不重定义）：
  - `sourceText` 含与 `markupTable` 对应的占位符引用 `<xN>` / `</xN>` / `<xN/>`；
  - `markupTable` 只读；`kind` 为 `paired`（`openingText`/`closingText`）或 `standalone`（`originalText`）；
  - `targetText` 未翻译为 `null`，不得用空串代替；`confirmationStatus`：`pending` / `translated` / `confirmed`；
  - `version` 乐观并发版本，保存成功后递增；`chapter` 非 epub 为 `null`；
  - 受保护块不可编辑；重新提取生成新分段 ID、旧 ID 不复用、`extractionRevision` 递增。
- **占位符语法**：`N` 为正整数，与同一分段 `markupTable[].id` 对应；AI 与人工译文均不得改写/删除/新增占位符（ADR-0002）。
- **错误响应**：统一 Problem Details；`400` 请求格式错误、`401` 鉴权失败、`403` 已认证无权、`404` 资源不存在、`409` 冲突（游标/修订/乐观锁）、`422` 语义/解析失败、`500` 服务端错误不暴露内部细节。
- **术语红线**（CONTEXT.md）：确认=分段确认状态（任务层面说完成/失败）；违规=规则引擎检出；错误=系统/接口故障；AI 二轮审查产出叫「审核意见」，不叫评分/报告。

## 5. 交叉引用规则

- 新文档默认引用《鉴权与基础接口约定》，不重复鉴权内容。
- 涉及分段/占位符/受保护块/提取修订时引用《文件导入拆解与导出接口约定》既有语义，不重复定义。
- 本文档未定义、由后续任务补充的内容（如任务列表接口补充进度字段）写成「预留」条款：「由后续 XX 接口约定补充，且不得改变本文既有字段语义」。
- 相邻功能文档（术语、TM、规则检查、任务管理）之间出现共享概念时，先定义者为准，后写者引用。
